# Associate Expense Management System

## Cool Features We Built

- **Microservices Architecture**: A scalable backend built with Spring Boot, dividing responsibilities into dedicated services (ApiGateway, EntitiesService, ExpenseService, IdentityService, UserService, and ServiceRegistry).
- **Service Discovery**: Seamless internal routing and discovery using Spring Cloud Netflix Eureka.
- **API Gateway**: Centralized entry point to manage, route, and secure all incoming requests to our microservices.
- **Secure Authentication**: Implemented robust security with Spring Security and JWT (JSON Web Tokens) for authentication and authorization.
- **Modern React Frontend**: A responsive, dynamic user interface built with React.js, featuring interactive charts (Chart.js) and elegant notifications (React Toastify).
- **Containerized Database**: Utilizes a MySQL database running efficiently within a Docker container.
- **Inter-service Communication**: Efficient, synchronous communication between microservices using Spring Cloud OpenFeign.
- **Deployment Ready**: Fully containerized applications with Dockerfiles and `docker-compose.yml`, along with Kubernetes (`k8s`) manifests for orchestration.
